# Games available in Zarcade

This file describes how each machine works. Playable machines are live on the
arcade floor. Soon machines are planned but not built yet.

## Unseen

Status: playable

How it works:
You are asked to send a small payment. You pick: hide it, or send it in the
open. Then you see exactly what a stranger can see afterwards. You install
nothing and hold no keys. The house wallet pays real testnet money either way.

Hidden: the payment goes into the private pool. The network keeps no amount,
no sender and no receiver.

Open: the payment goes to a transparent address. Anyone can follow where it
went and how much moved.

## The Crowd

Status: playable

How it works:
You play the stranger. The arcade hands you its whole record book, every
payment it ever made, and asks you to read what you can from it. Some rows tell
you plenty. Some tell you nothing at all.

Open payments leave a trail: the time they landed, the amount, and the address
they paid. Shielded payments stay sealed.

## The Proof Puzzle

Status: playable

How it works:
You set a secret three-digit code inside the safe. The Watcher asks three
yes-or-no questions about your code. You answer yes or no. The safe checks each
answer against the code inside it and only says open or shut. If all three
match, the payment moves. The Watcher never sees the code.

## The Double-Spend Heist

Status: soon

How it works:
Catch a cheater spending the same coin twice. This machine is not built yet.

## The Auditor's Key

Status: soon

How it works:
Give a trusted person a key to look at your payments. Looking is not spending.
This machine is not built yet.

## The Vault Run

Status: soon

How it works:
Move coins between the public side and the private side without leaving a
trail. This machine is not built yet.
