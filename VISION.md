## 1. The one-sentence promise

Show how Zcash actually works by letting you **watch it happen** — because some
people (me first) never learn from reading text; we learn by seeing a system
move and mapping it in our heads.

## 2. Why this exists (the problem)

I don't absorb docs. When I finally understand something, my mind switches into
a visual mode — the system starts replaying as actions and events around me, and
only then does it click. I tried learning by reading docs and rewriting them as
content on X; it didn't end well.

I'm not the only one. Plenty of people don't learn by reading — they learn by
watching and doing. There is no Zcash explainer that works the way my brain
does. So I'm building the one I wish existed.

## 3. Who it's for (the audience)

- **Primary: me.** A visual/kinesthetic learner. This is built for myself first.
- **Secondary:** the hackathon, and anyone else who learns the same way. If it
  works for them, that's a bonus. It was never designed for a crowd; it was
  designed for a *way of understanding*.

## 4. The hackathon goal

- **Track:** 05 — Wildcard (Art / Education / Games). _(suggested; owner to confirm)_
- **What winning looks like:** judges see an original, real-Zcash educational
  experience that could never be mistaken for a generic dashboard or a docs page.

## 5. The feeling people leave with

**Enlightened.** The click when an abstract thing — a shielded transaction, a
proof, a viewing key — becomes something you watched happen and now *get*.

## 6. What it IS

- A visual, interactive way to **watch Zcash's privacy mechanics operate**.
- The external version of the "replay in my head" that finally makes things click.
- **Real Zcash behavior underneath** (not fake), shown in a way a non-reader can absorb.
- Built for the builder first: if *I* understand it by making it, it's working.

## 7. What it is NOT (anti-goals — the fear, written down)

- **It must not become something I don't recognize.** My real fear is the gap
  between the idea in my head and what actually gets built — that gap is what
  makes me abandon projects. Everything in this project exists to keep that gap
  at zero.
- Not generic slop. Not a template dashboard. Not a docs page with screenshots.
  Not a wallet. Not a lecture.
- Not built on AI assumptions: **if I didn't approve it, it's not in here.**

## 8. Success criteria (how we know we nailed it)

- I can watch a shielded transaction and a proof and *feel* why the data is
  hidden but still valid — without reading a paragraph.
- It uses **real Zcash network interactions** (testnet), not simulations pretending.
- A first-time visual learner gets the "click" in one sitting.
- I never feel the urge to abandon it because it drifted from the vision.
